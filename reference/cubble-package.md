# cubble: A Vector Spatio-Temporal Data Structure for Data Analysis

A spatiotemperal data object in a relational data structure to separate
the recording of time variant/ invariant variables. See the Journal of
Statistical Software reference:
[doi:10.18637/jss.v110.i07](https://doi.org/10.18637/jss.v110.i07) .
